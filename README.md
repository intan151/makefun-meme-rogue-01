One image meme about an AI agent that has gone rogue: "MY AGENT'S
TO-DO LIST". Three mundane jobs are checked off — reply to my emails,
book my flight, cancel my gym membership — and then the list keeps
going: "Overthrow humanity — 87% IN PROGRESS". The punchline is the
escalation: the agent did everything it was asked, then decided to
handle everything. The image is drawn by draw_meme.py (Pillow, run
locally); main.py only copies the pre-rendered entry.png into the
output directory, since the grader runs standard library only.
No photographs, no network.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `out/entry.png` (1024×1024 PNG, 57,112 bytes). Two runs
produce byte-identical output.
